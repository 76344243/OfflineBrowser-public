# Security policy

Please do not publish a suspected vulnerability in a public issue first.
Report it through GitHub's private vulnerability reporting for this repository
when available, or contact the maintainer privately through GitHub.

Include the affected version or commit, the smallest reproducible example, the
expected and observed behavior, and whether the issue involves stored website
data, URL rewriting, local-server authorization, cookies, or archive
integrity. Do not include real credentials, private archives, or personal data
in a report.

OfflineBrowser intentionally restricts several web capabilities and is not a
general-purpose security boundary for arbitrary hostile web content. A report
should distinguish an implementation defect from one of the documented
compatibility limitations.
